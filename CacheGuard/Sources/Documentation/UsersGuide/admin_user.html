Administrator Users

Only authenticated users are permitted to administer and configure a CacheGuard appliance. The primary administrator user is named "admin". This user exists by default in the system and possesses the highest level of privilege.

Secondary administrator users with reduced privileges can be added to the system. Secondary administrators are authorised to read the configurations but cannot modify them (only the "admin" user has this privilege). Certain secondary administrative operations, such as cache loadurl, can be executed by secondary administrators. The admin user command allows you to manage secondary administrator users.

To create a new administrator user called "john", log in as the "admin" user first and then use the following commands:

  • admin user add john
  • apply
When invoking the "admin user add john" command, the "admin" user is prompted to choose a temporary password for "john". Once the apply operation is completed, the administrator user named "john" can log in. The first time a secondary administrator logs in to a CacheGuard appliance, they are required to change their password by entering a compliant one (refer to the password command to learn more about permitted password formats).
