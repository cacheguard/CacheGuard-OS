Define QoS for routed traffic on a logical network interface using QoS routing rules. Routed traffic is traffic that traverses a logical network interface (i.e. it is not destined for the appliance itself). With a QoS routing rule, you can shape the ingress (incoming) and egress (outgoing) traffic of a logical network interface based on the source and destination of the traffic.

To correctly shape routed traffic, you should consider that Egress traffic flows from a Source to a Destination, while ingress traffic flows in the opposite direction. Note that when traffic traverses the appliance, it enters through one network interface and exits through another. Consequently, the egress direction on one interface corresponds to the ingress direction on the other, and vice versa.

The QoS value is either a percentage (ending with %) of the bandwidth limit or an absolute value in Kbps. If the optional DSCP (Differentiated Services Code Point) value is specified, the DSCP field in IP packets will be set to the specified value.
