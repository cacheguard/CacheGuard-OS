Define the QoS for routed traffic via the appliance using QoS rules. With a QoS rule you can reserve an amount of bandwidth for incoming (towards the appliance) and outgoing (from the appliance) traffic from a logical network interface according to the used protocol, the source IP & Port and the destination IP & Port. Please note that in a QoS rule, an ingress (incoming) traffic comes from the source and goes to the destination while the related egress (outgoing) traffic comes from the destination and goes to the source (in the opposite sense). The QoS value is a percentage (ended with %) of the bandwidth limit or an absolute value in Kbps. If the optional DSCP (Differentiated Services Code Point) value is specified, the DSCP field in the IP packets will be set with the specified value.
