I – [About CacheGuard-OS]

CacheGuard-OS is a network-appliance-oriented operating system based on a custom-hardened version of Linux, built from scratch and specifically designed to manage network security and traffic optimisation. The result is a powerful, turnkey solution that can be deployed both rapidly and efficiently within your networks.

All CacheGuard software components are released under the GNU General Public License v3. However, the aggregation of these components, together with other Open Source Software (as defined by the OSI), forming the “CacheGuard-OS”, is licensed under the “CacheGuard-OS Licence Agreement”.

CacheGuard-OS integrates multiple security and traffic optimisation technologies into a single, fully functional appliance. Technologies such as Proxy, Reverse Proxy, Firewall, VPN, Antivirus, Bandwidth Shaping, Caching, HTTP Compression, URL Filtering, Web Application Firewall, Malware Filtering, and SSL Inspection are all combined within a single operating system, delivering a high level of integration.

II – [Installation]

This bootable CD-ROM contains all the components required to transform a bare-metal or virtual machine into a ready-to-use network appliance. Please refer to the “Getting Started” section of the User’s Guide for instructions on how to install CacheGuard-OS.

Caution: CacheGuard-OS is not an application but a full operating system and therefore requires a dedicated machine. You can find the User’s Guide on this CD-ROM at cacheguard_doc/guide/index.html.
